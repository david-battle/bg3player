# BG3 Knowledge Base — Expansion Plan

Plans the next phases of the knowledge base beyond the shipped magic-equipment
reference. New categories follow the same established pattern: bg3.wiki-sourced,
machine-curated, generated by scripts into browse-able markdown + a per-category
master JSON. This is a plan document, not a spec; adjust fields while building.

## Decisions (2026-08-30, user)

1. **No spoiler restrictions** — full story detail is welcome everywhere.
2. **Quest index is planned (exhaustive) but deferred** out of the first
   implementation; the equipment source lists get to prove themselves first.
3. **Companion scope** includes origin characters, hirelings, and recruitables
   (Halsin, Jaheira, Minsc, Minthara).
4. **Consumables are the immediate next implementation**; it overlaps the
   merchant catalog (a separate, larger category).
5. **Keep the established data shape**: browse-able markdown + master JSON +
   pipeline scripts per category.

## Guiding rules (inherit from AGENTS.md / README.md)

- Accuracy over coverage; mark unknowns rather than guessing.
- All content derives from bg3.wiki (CC BY-NC-SA 4.0 / CC BY-SA 4.0
  dual-licensed); keep attribution in README.
- Regenerable caches (raw HTML, parsed intermediates) stay gitignored; tracked
  data is the per-category master JSON(s) plus the rendered markdown.
- Scripts: `scripts/fetch_*_pages.py` (rate-limited API cache),
  `scripts/parse_*_pages.py` / `scripts/build_*.py` per category. Reuse the
  existing item-pipeline helpers only where a real third use shows up; do not
  pre-build a shared framework.
- Cross-reference categories wherever they overlap (see "Cross-links").

## Phase 1 — Consumables + alchemy (next implementation)

Split `knowledge_base/consumables/` to keep files readable:

- `potions_elixirs.md` — potions and elixirs (incl. Elixir of Bloodlust, Hill
  Giant Strength, etc. — build-critical).
- `scrolls.md` — all scrolls.
- `arrows_coatings_grenades.md` — special arrows, coatings, throwables/bombs.
- `camp_supplies.md` — food/camp supplies (lighter; maybe fold into above).
- `alchemy.md` — ingredients, extract/combine recipes, where ingredients are
  found; links potions/elixirs to their recipes.

Fields per item: name, type/rarity, effect (plain language), duration,
where obtained (merchant / loot / crafted), recipe + ingredients.

Sources: bg3.wiki potion/scroll/arrow/alchemy pages + item pages. Ties to
merchant catalog (#12): record "sold by" inline from each item's page so Phase 1
needs no separate merchant pass.

## Phase 2 — Build & character reference (recommended first tranche)

### 2a. Companions (`companions.md`)
Origins (Astarion, Gale, Lae'zel, Shadowheart, Wyll, Karlach), recruitables
(Halsin, Jaheira, Minsc, Minthara), Dark Urge, and hirelings (Withers' roster).
Fields: race, default class, starting ability scores, skills, personal quest
breakdown per act, recruitment location/timing/requirements, missable windows,
romance basics, notable gear/role affinities (cross-link to equipment KB).

### 2b. Classes + subclasses (`classes_subclasses.md`)
Each of the 12 classes: role, hit die, primary abilities, saving throw + skill
profs, armour/weapon profs, spellcasting type (full/half/third/cantrip), key
features, **what distinguishes each subclass** (features, playstyle, stat
priority), and brief multiclass notes. No full level tables needed for the AI
to give good advice — keep concise per-subclass distinguishing text.

### 2c. Races + subraces (`races.md`)
Race/subrace traits: ability bonuses, size, speed, darkvision, weapon/armour
profs, unique traits, spell-like abilities. Companion default races link here.

### 2d. Feats (`feats.md`)
Every feat: prerequisites, what it grants (plain language), whether it includes
an ASI. ~60 entries; common build question.

### 2e. Backgrounds (`backgrounds.md`)
Skills + background feature per background (small).

### 2f. Permanent buffs & lasting rewards (`permanent_buffs.md`)
The user's named category. Cover: Auntie Ethel's Hair, Mirror of Loss, Potion of
Everlasting Vigour (+2 STR), Volo's Ersatz Eye, Zaith'isk / Awakened,
Astral-Touched Tadpole, Loviatar's Blessing, Dark Urge Slayer, plus anything
similar found in research. Fields: effect, how obtained, act/location,
missable/exclusivity notes, party-wide vs per-character. Enumerate exhaustively
from wiki categories at build time rather than relying on this starter list.

### 2g. Illithid powers (`illithid_powers.md`)
Full tadpole power tree: each power, cost, effect, act availability, evolved
(Awakened) versions, half/partial vs full ceremorphosis, bonuses for consuming
tadpoles. Overlaps #7 (Astral-Touched Tadpole).

### 2h. Conditions & effects glossary (`conditions.md`)
Every condition/effect items reference (Radiating Orb, Reeling, Arcane Charge,
Luminous, Bleeding, etc.): what it does, duration, recovery, common sources.
Directly improves the shipped equipment KB (item effects become resolvable).

## Phase 3 — Completion reference

### 3a. Achievements (`achievements.md`)
All ~54 achievements: unlock condition, act-locked/missable flags,
difficulty-specific ones. Source: bg3.wiki achievements.

### 3b. Honour Mode / difficulty (`honour_mode.md`)
Legendary Actions, single-save rules, Tactician/Honour differences, custom-mode
options. Small file; only the mechanics, not full boss guides.

## Phase 4 — Depth (planned, deferred)

### 4a. Merchant catalog (`merchants.md`)
Every merchant: location, act, name, notable stock (equipment + consumables),
restock rules. Overlaps Phase 1 (inline "sold by" data) — build as its own
comprehensive category later, cross-checking against Phase 1 findings.

### 4b. Quest index + rewards (`quests/`, exhaustive, deferred)
Major quests per act, objectives, rewards/outcomes, decisions that lock out
loot, missable windows. **Explicitly deferred per decision #2**; revisit once the
item source lists (equipment + consumables) prove sufficient.

## Cross-links

- Equipment KB `<->` conditions glossary: item effects reference conditions.
- Equipment KB `<->` companions: recommended gear/roles per companion.
- Companions `<->` classes/races: default class/race.
- Permanent buffs `<->` quests/acts: where and when each is obtainable.
- Consumables `<->` alchemy `<->` merchants: recipes and where to buy.

## Build order

1. Phase 1 (consumables + alchemy).
2. Phase 2 in any order; start with companions + feats + permanent buffs +
   conditions (smallest, highest build-advice value), then classes, races,
   backgrounds, illithid powers.
3. Phase 3 (achievements, honour mode) — small, can slot in anytime.
4. Phase 4 only if the source lists prove insufficient.

## Out of scope (not planned)

- Full enemy/NPC bestiary and boss strategy guides.
- Generic D&D 5e rules (skill/combat basics) — the AI already knows these.
- Mod support, console commands, patch-notes-as-news.
- Music/audio/visual assets.
